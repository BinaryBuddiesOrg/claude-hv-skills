# core

Shared runtime that every domain Director and Producer relies on. Install it with any
domain plugin:

```
/plugin install core --marketplace BinaryBuddiesOrg/claude-hv-skills
```

```
skills/doctor/    inspect the machine: OS, CPU, RAM, GPU/VRAM, tools and versions, fonts; offer install recipes from TOOLBOX.md
skills/brief/     the common brief schema, out/<slug>/ layout, how to edit a brief and re-run
skills/deliver/   the five-label report, Look images, what counts as verified
```
